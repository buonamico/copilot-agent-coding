## Instructions
This repo is a starting point for exploring advanced features and configurations of GitHub Copilot in VS Code. There are no project files. Instead there are Agents, Instructions, Prompts, and Skills to help you build out your own project.

The specific Copilot configurations provided are set up to build an MCP server connecting to the Open Weather Map API. You can use them as-is to test out the features, or change them to fit your needs.

See [COPILOT_REFERENCE.md](COPILOT_REFERENCE.md) for a comprehensive rundown of what's provided and how to get started.
